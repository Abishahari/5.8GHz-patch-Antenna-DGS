# 5.8 GHz Microstrip Patch Antenna with Defected Ground Structure (DGS)

## Project Overview

This project focuses on the design and electromagnetic simulation of a
5.8 GHz microstrip patch antenna incorporating a Defected Ground Structure
(DGS) using Dassault Systèmes CST Studio Suite.

The design explores antenna geometry, meshing, and electric field
distribution for RF and microwave applications.

## Objectives

- Design a microstrip patch antenna operating near 5.8 GHz.
- Incorporate a Defected Ground Structure (DGS).
- Develop the antenna model using CST Studio Suite.
- Examine mesh visualization and electric field distribution.
- Understand the electromagnetic behavior of the antenna.

## Software Used

- Dassault Systèmes CST Studio Suite

## Simulation Workflow

1. Create the antenna geometry in CST Studio Suite.
2. Assign the substrate and conductor materials.
3. Configure the ground plane and DGS.
4. Define the excitation port and open boundary conditions.
5. Generate the computational mesh.
6. Run the electromagnetic solver.
7. Examine S-parameters and electric field distribution.
8. Evaluate radiation characteristics using far-field monitors.

## Expected Analysis

The project is intended to investigate:

- S11 and return loss
- Resonant frequency
- Impedance bandwidth
- Voltage Standing Wave Ratio (VSWR)
- Electric field distribution
- Radiation pattern
- Realized gain and radiation efficiency
